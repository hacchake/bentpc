# DSP 仕様書（BLIPPY BOOK 30 bent）

後で JUCE（C++）や Rust（nih-plug など）に移植するための、音の処理の設計メモ。
コードは `src/dsp/` にあり、DOM・Web Audio には一切依存しない。

## 全体の流れ

```
UI / MIDI / ホスト
   │ パラメーター値（src/params.ts）・キー押下・電源
   ▼
Engine（engine.ts） ─── 1サンプルずつ処理
   ├─ Firmware（firmware.ts）  … 電源・起動・モード・クイズ・死んだキー。鳴らす波形と液晶の内容を決める
   │     └─ SoundBank（soundbank.ts） … 波形 ROM。8kHz・8bit の波形を作ってキャッシュ
   │           ├─ speech.ts … フォルマント音声合成
   │           └─ tones.ts  … 矩形波メロディ・効果音・ドラム
   ├─ Chip（chip.ts） … 再生回路。波形を「クロック」で読み出す（ゼロ次ホールド）
   └─ アンプ部 … 1次ローパス(6.5kHz) → DCカット → 音量 → 電源ゲート
   ▼
モノラル出力（Worklet ではステレオ両chに複製）
```

## パラメーター

`src/params.ts` の `PARAMS` 配列がすべて。各項目は
`id / name / kind / min / max / default / labels / midiCC` を持つ。
DSP は `Float32Array(PARAMS.length)` で値を持ち、インデックスは配列の順番。

| kind | 意味 |
|---|---|
| continuous | ノブ（0..1） |
| stepped | 段階スイッチ。整数に丸める |
| toggle | 0/1 |
| momentary | 押している間だけ 1 |

VST3 化では、この表からそのままパラメーター一覧を作れる（momentary はホストのオートメーション対象外にしてもよい）。

## 乱数と再現性

- 乱数はすべて `rng.ts` の `Rng`（mulberry32、32bit 状態）。
- `hashSeed(...)`（FNV-1a の変形）で「個体シード＋用途名＋番号」から派生シードを作る。
  → 同じ個体シードなら、同じキーは必ず同じ音、死んだキーの位置も同じ。
- 個体シードの既定値：`DEFAULT_SEED = 0x7a11c0de`（engine.ts）。
- Firmware 内のクイズ出題なども、個体シードから作った Rng を順番に消費するので、
  同じ操作列なら同じ結果になる。

## 波形 ROM（SoundBank）

- すべて **8000Hz**（`CHIP_RATE`）で生成し、ピーク 0.9 に正規化してから **8bit 量子化**（±127 段）。
- 生成結果は文字列キーでキャッシュ（例：`letter:K`、`drum:5`）。

### 音声合成（speech.ts）

簡易フォルマント合成。Klatt 型の直列共振器を使う。

1. 音素列（例 `"K AE T"`）を `phonemes.ts` の表で「区間」の列に展開。
   各区間：`F1,F2,F3`（Hz）、`av`（有声の強さ）、`af`（摩擦ノイズ）、`fn/fbw`（摩擦ノイズの中心と帯域）、
   `asp`（気息ノイズ）、`dur`（ms）。破裂音は「閉鎖→破裂→気息」の3区間。
   `next` 指定の区間はフォルマントを次の有声区間から借りる（H、破裂後の気息）。最後の母音は 1.45 倍に伸ばす。
2. 10ms（80サンプル）ごとの**フレーム**でパラメーターを更新（段差状＝LPCチップ風）。
   フォルマント周波数は前区間から min(40ms, 区間長/2) かけて直線補間、振幅は 12ms で補間。
   振幅はさらにサンプル単位で 3ms の1次平滑。
3. 音源：二乗余弦の声門パルス（開放率 0.6）を1次差分したもの × `VOICE_GAIN(6)`。
   ピッチは開始値→終了値（既定 0.72 倍）へ直線で下がり、前半に +6% の山、フレームごとに ±1.2% のゆらぎ。
4. 有声路：`(声門 × av + ノイズ × asp × 0.35)` → 共振器 F1(帯域70) → F2(100) → F3(150)。
   共振器：`y = a·x + b·y1 + c·y2`、`r = exp(-π·BW/fs)`、`c = -r²`、`b = 2r·cos(2πF/fs)`、`a = 1-b-c`。
5. 摩擦路：ノイズ → RBJ バンドパス（ピーク 0dB、Q = fn/fbw、fn は 0.47fs 以下に制限）× af × `FRIC_GAIN(2.0)`。
6. 出力 = 有声路 + 摩擦路 → ピーク正規化。

声の高さは個体ごとに 175〜214Hz（シードで決定）。

### 音声以外（tones.ts）

- 矩形波（50%/25%/12.5%）、三角波、ノコギリ波。位相累積のみ、帯域制限なし（わざと折り返す）。
- `melody`：音符列（MIDI番号, ms）。`decay` で指数減衰。
- `sweep`：指数カーブのピッチ変化。`noise`：サンプル保持・1次ローパス付きノイズ。
- ドラム8種（キック・スネア・ハット・オープンハット・タム・クラップ・カウベル・ザップ）、効果音10種を、
  キーごとに派生シードで細部を変えて生成。

## Firmware（モードとキー割り当て）

キー番号：0..25 = A..Z、26..29 = 機能キー F1(♪) F2(?) F3(★) F4(OK)

| モード | 文字キー | 機能キー |
|---|---|---|
| 0 ABC | 文字名の読み上げ（エー、ビー…） | ♪=メロディ ?=決まり文句 ★=効果音 OK=正解音＋GOOD JOB |
| 1 WORD | 単語（APPLE, BALL, CAT…） | 同上 |
| 2 TUNE | キーごとの短いメロディ | 同上 |
| 3 PIANO | ハ長調の音階（A=C3 から Z まで） | C/F/G/Am のアルペジオ |
| 4 DRUM | ドラム音（8種を循環） | 1小節のドラムパターン4種 |
| 5 SFX | 効果音（10種を循環） | ABC と同じ |
| 6 QUIZ | 出題された絵の頭文字を当てる。正解→ピンポン＋RIGHT、次の問題へ。不正解→ブッブー＋NO/TRY AGAIN | ♪=もう一度 ?=次の問題 ★=ヒント OK=GOOD JOB |
| 7 SAY | 「K IS FOR KING」 | ABC と同じ |

- **死んだキー**：モードごとに 2〜3 個（`hashSeed(seed,'dead',mode)`）。押しても音は出ず、液晶だけ反応。
- **単音**：新しい音が鳴ると前の音は止まる（おもちゃと同じ）。
- 音が終わったとき Firmware の `onSoundEnd()` が呼ばれ、クイズの次の問題や起動後の画面切り替えを行う。
- 電源ONで起動音＋「HELLO」。鳴り終わるまでキーは効かない。
- LOOP スイッチが下（MUTE）だと電源が入らず、出力も無音。

## 再生回路（Chip）

- 読み出し位置 `pos`（チップのサンプル単位、小数）に `clock / hostRate` を毎サンプル足す。
- 出力は `buf[floor(pos)]`（ゼロ次ホールド・補間なし）。8kHz→48kHz の段差がそのまま折り返しノイズになる。
- フェーズ2でここにグリッチ・ループ・ストレッチを追加する予定。

## アンプ部

- 1次ローパス：`lp += (x - lp) · (1 - exp(-2π·6500/fs))`
- DCカット：`y = x - x1 + 0.995·y1`
- 音量：`volume²` を 1次平滑（係数 0.002/サンプル）
- 電源ゲート：0/1 を係数 0.01/サンプルで平滑（ポップ防止）

## 液晶の表示状態（DisplayState）

DSP 側は「何を表示するか」だけを決める：`screen`（off/boot/idle/key/quiz）、`mode`、
`big`（大きな文字）、`sprite`（ドット絵名）、`text`（下の行）、`mark`（ok/ng/q/dead）。
描画は UI 側（`src/ui/lcd.ts`、128×64 の 1bit）。VST 版の UI も同じ状態から描けばよい。
