# 自動作曲の仕様（AUTO COMPOSER）

AI は使わない。**ルール＋シード付き乱数**で作る（オフライン・無料）。同じシード＋同じ設定なら、必ず同じ曲になる。
作った曲はふつうのシーケンサーの曲データなので、あとから手で直せる。

## ファイル

| ファイル | 中身 |
|---|---|
| `src/compose/types.ts` | 共通の形。`Composer`（作曲方法）は差し替えられる（将来「言葉から作る」を足すときもこの形） |
| `src/compose/styles.ts` | **スタイルの表**（構成・テンポ・グリッチの多さ・クラッシュのしきい値など）。「このスタイルはもっと〇〇」はまずここ |
| `src/compose/plan.ts` | 設計図：構成（セクションと長さ）・盛り上がりと壊れ度・コード進行・クラッシュの場所 |
| `src/compose/rules.ts` | ルールの作曲：設計図 → おもちゃごとの作曲係 → 鍵・セクション作り直しの処理 |
| `src/compose/toys/*.ts` | おもちゃごとの作曲係（blippy・piko・dj・vroom・typo・tele） |
| `src/compose/harmony.ts` | 共通の道具：コード・メロディ（モチーフの繰り返し）・ベース・ドラムの型・クラッシュの区間 |
| `src/compose/context.ts` | 作曲係に渡す材料、電源とクラッシュの入れ方 |
| `src/compose/panel.ts` | 自動作曲ユニット（おもちゃの右の緑の基板） |
| `scripts/compose-test.ts` | 検査（全スタイル×長さ、同じ設定→同じ曲、鍵、セクション作り直し、鳴る、クラッシュ）。`out/compose-*.wav` に書き出す |

## 設定（パネル）

| 部品 | 中身 |
|---|---|
| 自動作曲（赤い大きなボタン） | 新しいシードで作って、シーケンサーに書き込み、頭から鳴らす |
| SEED | 表示と手入力。入れるとそのシードで作る |
| この設定で作り直す | 今のシードのまま、変えた設定（STYLE など）で作り直す |
| STYLE | 素朴 / ビート / アンビエント / ノイズ / 崩壊 |
| 壊れ度 | 0〜100%：グリッチの数・歪み・クラッシュの入りやすさ |
| LENGTH | 30 秒 / 1 分 / 2 分 / 3 分 |
| BPM | スタイルごとの範囲で。STYLE を変えるとそのスタイルの既定値に戻る |
| このセクションだけ作り直す | 選んだセクションだけ、別の乱数で作り直す（他の場所は変わらない） |
| 🔒（シーケンサーのトラック名の横） | 鍵を掛けたトラックは、作り直しても残る |

## 作り方

1. **設計図**（`planSong`）
   - 長さ（秒）× BPM から小節数を出し、スタイルの構成の重みで配る（2 小節単位・最低 2 小節）。短い曲では優先度の低いセクションを省く。
   - セクションごとに「盛り上がり（energy）」と「壊れ度（= 設定の壊れ度 × スタイルの倍率）」を持つ。
   - コード進行は 7 種からシードで選ぶ（ハ長調／イ短調。ドレミの数字キーがハ長調なので合う）。
   - クラッシュ：崩壊セクションには必ず。ほかのスタイルは、壊れ度がスタイルのしきい値（`crashAt`）以上ならブレイクで。
2. **乱数**：`シード × おもちゃ × パート × セクション × 作り直し回数` ごとに別の流れ。
   だから、パートに鍵を掛けて他を作り直しても、セクションだけ作り直しても、関係ない所は変わらない。
3. **鍵**：鍵の付いたトラックだけ残し（ほかのおもちゃのトラックも、鍵があれば残る）、同じパートは新しく作らない。
4. **セクションだけ作り直す**：曲に残した設定（`song.compose`）で同じ設計図を作り、そのセクションの範囲の音符・ツマミの点だけを、鍵の無い自動作曲トラックで差し替える。

## トイPC の作曲係（`toys/blippy.ts`）

トイPC は 1 音ずつしか鳴らない（新しい音が前の音を切る）。そこで、セクションごとに **16 分音符のスロット** を
「文字キー（声・リズム）」と「ドレミ」のどちらが使うか先に決めてから、中身を作る。

| パート | 中身 |
|---|---|
| 声・リズム（`blippy:keys`） | 文字キーと機能キー、モードの切り替え |
| ドレミ（`blippy:melody`） | ドレミの数字キー（どのモードでも鳴るので、声・リズムに鍵を掛けても合う） |
| 改造パーツ（`blippy:mods`） | POWER ON（起動音「HELLO」から始まる）、CRASH、GLITCH 1〜5、BASE、LOOP HOLD / RELEASE、STRETCH、LFO、DIST |

### 中身の作り方（テクスチャ）

| 名前 | モード | 中身 |
|---|---|---|
| say | SAY | 2 小節ごとに「K IS FOR KING」、あいだにメロディ |
| callmel | WORD | 3 小節半メロディ → 4 小節目の後半で単語を呼ぶ（KING! CAT!）。ときどき機能キーで返す |
| spell | ABC | 単語のつづりを 8 分音符で読み上げ（K・I・N・G）と、メロディを 1 小節ずつ交互に |
| drum | DRUM | キック・スネア・ハットを 1 本の線で（1 音ずつ）。隙間にドレミが入る。4 小節目はフィル |
| chars | WORD | キャラ連打（8 分音符、4 小節目の後半は 16 分） |
| sfx | SFX | 効果音をばらばらに |
| quiz | QUIZ | ばらばらの文字 → ほとんど「NO!」 |
| long | （SAY のまま） | 長い音：鳴らした音を LOOP HOLD でつかんで、STRETCH・LFO でうねらせる |

| スタイル | イントロ | Aメロ | 展開 | サビ | ブレイク | その他 |
|---|---|---|---|---|---|---|
| 素朴 | say | callmel | — | spell | — | ラスト say |
| ビート | drum | drum | drum | chars | say | エンド spell |
| アンビエント | say | — | — | — | — | ただよう・ふくらむ long、おわり say |
| ノイズ | sfx | — | — | chars | quiz | ノイズ sfx |
| 崩壊 | say | callmel | drum | chars | — | 崩壊 quiz ＋ クラッシュ（最後は再起動の「HELLO」で終わる） |

### 繰り返し

- 単語のテーマ（どうぶつ・おしろ・うちゅう・おやつ・おもちゃ）を曲ごとに 1 つ選び、その単語だけを使う。
- メロディのモチーフ（2 小節）は **セクションの種類ごとに 1 つ**。同じ種類のセクションは同じモチーフ（Aメロが戻ってくる）。
- モチーフを繰り返し、2 回目は終わりを変え、4 回目は少し高く始める。拍の頭はコードの音にそろえる。

### 改造パーツ

- GLITCH：1 小節あたり `壊れ度 × スタイルのグリッチ × 盛り上がり × 3` 回くらい。拍の頭で押す（音と拍がそろう）。
- BASE：壊れ度が低いと 1〜2、高いと 3〜5。
- DIST：セクションの中でじわっと上がる。とても壊れているセクションでは FOLD に。
- LFO：展開・ふくらむ・ノイズで深く。
- LOOP HOLD → LFO 全開 → RELEASE：盛り上がるセクションの最後の 2 小節で（壊れ度が高いほど入りやすい）。
- 起動中（最初と再起動のあと約 1.6 秒）とクラッシュ中は、キーを置かない（押しても鳴らないため）。

### 音が出ないキーについて

このアプリのトイPC は「全部のキーで音が出る」ように作ってある（死にキーは無い）。
そのため「崩壊」スタイルでは死にキーの代わりに、QUIZ モードの「NO!」連打・クラッシュ・再起動を使う。

## ほかのおもちゃの作曲係

どれも、同じ設計図（構成・コード・盛り上がり・壊れ度・クラッシュ）から作る。だから、スタジオで何台並べても、コードとセクションがそろう。
メロディは共通の道具（`harmony.ts` の `makeMotif` / `realize`）：2 小節のモチーフをセクションの種類ごとに 1 つ作り、繰り返して少し変える。

| おもちゃ | パート | 中身 |
|---|---|---|
| TELEKEY | ビート | 楽器キーの KICK・SNARE・HAT（スタイルごとの型、4 小節目はフィル。ノイズはノイズも） |
| | 楽器 | コードにソ・ドがある小節でチャイム（BLIP・CHIRP・BEEP）、フレーズの終わりにザップ |
| | 映像グリッチ | セクションごとにグリッチの「組」（テレビが乱れる・デジタルが壊れる・形が壊れる・時間が壊れる・とがる…）を 1 つ選び、拍の頭で入れる。多さは盛り上がり × 壊れ度。フレーズの区切りで大きく。セクションの頭でキュー、終わりで FREEZE、サビで一発グリッチ（BASE も変える）と HOLD → RELEASE |
| | 改造パーツ | GLITCH AMT・LFO・FEEDBACK・DIST・混線を盛り上がりと壊れ度に合わせて |
| PIKOTONE | コード | 鍵盤で和音（素朴・アンビエントは伸ばす、ビート・ノイズは裏打ち）。セクションごとに ORCHESTRA の音色 |
| | メロディ | モチーフの繰り返し（イントロはベースだけ） |
| | リズム | 内蔵リズムの TEMPO を曲の BPM に合わせ、4 小節ごとに START で頭から回し直す。4 小節目はパッドのフィル |
| | 改造パーツ | 電圧 Starve（CPU / AMP POWER：壊れるほど遅く・低く・よれる）・FIZZ・DIST・HIPASS・FEEDBACK・ピッチ曲げのタッチ・GLITCH・VIBRATO |
| SPIN-TOT | 鍵盤 | 静かなセクションはベース（BASS の音色）、にぎやかなセクションはメロディ |
| | パッド | フレーズの区切りと、サビの 2・4 拍で効果音 |
| | リズム | 28 パターンのうち曲の BPM にいちばん近いものを選び、TEMPO ボタンで合わせ、4 小節ごとに回し直す（ノイズ・崩壊は隠しパターンも候補） |
| | 改造パーツ | スクラッチ（ディスクに触って DISC SPEED を前後に）・DIST 1/2・FEEDBACK（ソース切替）・STOP でがくっと止める |
| VROOMBOX | エンジン | 最初に START を押し続けてエンジンをかけ、点火の音程でベースライン。クラッシュの後はかけ直す |
| | ダッシュボード | クラクション（裏拍）・衝突音（フレーズの頭）・ラジオの選局・ウインカー / ワイパー / サイレン |
| | 改造パーツ | アクセル・ギア・REDLINE・SPARK・TURBO（盛り上がりの最後）・気筒の間引き（壊れるほど点火が抜ける）・TURBO FB・RADIO BLEED |
| TYPOTRON | 音 | 文字キーの段で弾く（音階は MAJOR）：上の段でメロディ、下の段で和音 |
| | ドラム | テンキーのドラム（CRASH・CLAP・COW・ZAP も） |
| | 故障・ノブ | GHOST・SCAN・BOUNCE・OVERFLOW、フレーズの終わりに STUTTER、壊れていると CORRUPT。DRIVE・CRUSH・ECHO・DECAY・TONE・WAVE |

## 直し方（例）

| 言われたこと | 直す場所 |
|---|---|
| ビートをもっと速く | `styles.ts` の `beat.bpm` と `bpmRange` |
| 素朴をもっと静かに・短いセクションに | `plain.sections` の `energy`・`w` |
| ノイズのグリッチをもっと多く | `noise.glitch` |
| クラッシュをもっと入れて | `crashAt` を下げる（0 なら壊れ度 0 でも入る） |
| ドラムの型を増やして | トイPC は `toys/blippy.ts` の `DRUM_LINES`、ほかは `harmony.ts` の `DRUMS` |
| 映像の崩れ方を変えて | `toys/tele.ts` の `PALETTES` |
| 連打の並びを変えて | `CHAR_PATTERNS` |
| 単語のテーマを増やして | `THEMES` |
| メロディをもっと細かく | スタイルの `notesPerBar`、`RHYTHMS` |
