# DSP 仕様書：TYPOTRON TT-109（5台目・オリジナル設計）

PC の日本語 109 キーボードそのものを魔改造した、という設定の楽器。**目の前の PC キーボードでそのまま弾く**ことを最優先にした。
コードは `src/toys/typo/dsp/engine.ts`、キーの割り当て表は `src/toys/typo/params.ts`（`LAYOUT` / `NAV` / `NUMPAD`）。

## キー番号

`TYPO_KEYS`（LAYOUT の各行 → NAV → NUMPAD の順）の並び順がキー番号。各キーは `code`（KeyboardEvent.code、物理位置）・
`label`（JIS のキートップ）・`role`（役目）を持つ。MIDI ノートは `RAW_NOTE(1000) + ノート番号`。
どのキーを押しても、まず**打鍵音**（カチッ）が鳴る。

## 音のキー（4 段）

| 段 | キー | 列 |
|---|---|---|
| 0（低い） | Z X C V B N M , . / \ | 0〜10 |
| 1 | A S D F G H J K L ; : ] | 0〜11 |
| 2 | Q W E R T Y U I O P @ [ | 0〜11 |
| 3（高い） | 1 2 3 4 5 6 7 8 9 0 - ^ ¥ | 0〜12 |

- 音階の度数 `deg = 列 + 段 × 3 + 移調`、ノート `= 48 + 12·floor(deg / 音階の長さ) + 音階[deg mod 長さ] + 12·オクターブ`。
  1 段上がると 3 度数（長音階ならほぼ 4 度）上がるので、ギターのように同じ形で弾ける。
- 音階（F5〜F8）：MAJOR `[0,2,4,5,7,9,11]`、MINOR `[0,2,3,5,7,8,10]`、PENTA `[0,2,4,7,9]`、BENT `[0,1,4,5,8,11,12.5]`（わざと狂っている）。

## 機能キー

| キー | 機能 |
|---|---|
| Space | SUSTAIN：押している間、離した音も伸びる |
| 左 Shift / 右 Shift | 押している間 −1 / +1 オクターブ（押した後に弾いた音から） |
| Enter | 行バッファを 16 分音符でループ再生／停止 |
| Backspace | 行の最後の 1 音を消す（下がるチャープ音） |
| Esc | 行を全部消してループを止める（シャッという音） |
| Insert | 上書きモード：ループ中に弾くと、今鳴っている位置を書き換える |
| Delete | CORRUPT（押している間）：CRUSH を 0.85 以上にし、鳴っている音がときどきオクターブや 5 度に跳ぶ |
| Tab | STUTTER（押している間）：押した瞬間の直前 1/32 拍（`60/BPM/8` 秒）を繰り返す |
| CapsLock | LATCH：押した音が離しても鳴りっぱなし。同じキーをもう一度押すと止まる |
| ← → | ピッチベンド（押している間、BEND RANGE 半音まで 80ms で移動） |
| ↑ ↓ | 移調（音階 1 度数ずつ） |
| Home / End | テンポ ±5 BPM（60〜240） |
| PgUp / PgDn | 電源 ON / OFF |
| F1〜F4 | 波形 PULSE（25% パルス）/ SAW / BELL（3.5 倍の FM）/ NOISE（音程つきサンプル＆ホールド） |
| テンキー 0〜9・無変換・変換・かな | ドラム（1台目のドラム合成の流用、8kHz ROM） |

## 行バッファ（打った音の「行」）

- 音のキーを押すたびに `{ノート, キーの文字}` を末尾に足す（長さは無制限。液晶は入りきらなくなると横に流れ、ループ中は鳴っている所を追いかける）。液晶には打った文字がそのまま並ぶ。
- Enter でループ：`BPM × 4 / 60` Hz でステップを進め、前の音を離して次の音を鳴らす。

## キーボードの故障（改造・F9〜F12 で ON/OFF）

- **GHOST（F9）**：キーマトリクスのゴースト。押したキーの左右・上下の段の隣が、それぞれ GHOST ノブの確率で
  0〜20ms 遅れて音量 0.4・少し高め（+8 セント）で鳴る。
- **SCAN（F10）**：キーの読み取りが遅い。押している（ラッチ中も含む）キーを、SCAN RATE（2〜80Hz）で 1 つずつ順番に鳴らす。
  遅いとアルペジオ、速いとブザーのような多重音になる。
- **BOUNCE（F11）**：チャタリング。押すたびに `1 + floor(BOUNCE × 6)` 回、15〜45ms 間隔で音量 0.75 倍ずつ小さくなって連打。
- **OVERFLOW（F12）**：行バッファがあふれて暴走。ループの各ステップで 25% ランダムな位置へ飛ぶ、
  12% で ±12 半音のゴミの音、10% で別の音が同時に鳴る。

## 音源とエフェクト

- 12 音。エンベロープ：アタック 3ms → 押している間はレベル 0.35 へ、離すと 0 へ DECAY（50ms〜3s）で減衰 → 0.3 以下で 60ms のリリース。
- 流れ：音源×0.22 ＋ ドラム → TONE（1 次ローパス 200Hz〜12kHz）→ DRIVE（tanh、最大 26 倍）→
  CRUSH（`1+floor(8c)` サンプル保持、`12-9c` ビット）→ STUTTER → ECHO（0.75 拍、フィードバック 0.8·echo、ミックス 0.6·echo）
  → ＋打鍵音 × CLICK → DC カット → tanh → 音量²。
- 打鍵音：1.5ms のノイズ＋`1600 + 段×450` Hz の 4ms の響き＋180Hz の 8ms の「コトッ」。

## 状態

`status().leds`：`loop`、`latch`、`overwrite`、`ghost`、`scan`、`bounce`、`overflow`、`corrupt`、`stutter`。
`fx`：`oct`、`transpose`、`wave`、`scale`（画面のキーに音名を出すため）。
`display`：`line`（打った文字）、`cursor`（ループの位置）、`info`（波形・音階・BPM など）。
