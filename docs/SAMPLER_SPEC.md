# PAKU-PAKU 16（音を食べるサンプラー）仕様

スマホ・タブレット・PC のブラウザで使うサンプラー。見た目は「子ども用の録音おもちゃを魔改造した」もの。
定番のハードウェアサンプラー（パッド型の SP 系・MPC 系）の機能を、オリジナルの名前で網羅する。実在の製品名・ロゴは画面に出さない。

- ページ：`sampler.html`（ラック・スタジオの上のバーからも行ける）
- コード：`src/sampler/` にまとめる（あとでサンプラー単体のアプリに切り出せるように、ほかのおもちゃのコードには依存しない。使うのは `src/core/controls.ts` のノブと `src/core/rng.ts` の乱数だけ）
  - `src/sampler/dsp/` … 音の処理（DOM 非依存。将来 VST3 などに移すときはここだけ持っていく）
  - `src/sampler/worklet.ts` … AudioWorklet の殻
  - `src/sampler/host.ts` … AudioContext・マイク・ファイル読み込み
  - `src/sampler/store.ts` … ブラウザ内の保存（IndexedDB）
  - `src/sampler/main.ts`・`ui.ts`・`sampler.css` … 画面
- ステレオ（ほかのおもちゃはモノラル）

## 機能の対応表（定番機 → PAKU-PAKU 16）

| ベロシティ | パッドの押した高さ（上ほど強い）／ペンや感圧画面は筆圧。FIXED VEL で常に最大 | 1 |
| GATE / LOOP / REVERSE | パッドごとの GATE（押している間だけ）・LOOP（くり返し。GATE なしならもう一度押して止める）・REV（逆再生） | 1 |

| ポリ／モノ | POLY：オフだと同じパッドを押し直すと頭から（前の音は止まる）、オンだと重なる | 1 |
| ピッチ・ファイン・音量・パン | SOUND ページの 4 つのノブ | 1 |
| フィルター・エンベロープ | FILTER/ENV ページ：CUTOFF・RESO（ローパス）・ATTACK・RELEASE | 1 |
| スタート／エンド | SAMPLE ページ：START・END・MUTE GRP・VEL（ベロシティの効き） | 1 |
| サンプリング（外部入力） | REC → パッドを押す → 録音 → REC で止める。AUTO で「音が来たら録音開始」 | 1 |
| リサンプリング | RESAMPLE：自分の出している音をパッドに録る | 1 |
| ファイルの読み込み | 📂：WAV・MP3 など（ブラウザが読めるもの）。PC はパッドへドラッグ＆ドロップも | 1 |
| コピー・消去 | COPY（選んだパッド → 押したパッド）・DEL | 1 |
| 全停止 | STOP | 1 |
| MIDI 入力 | ノート 36〜51 → いまのバンクのパッド 1〜16（左下が 1）。ベロシティ付き | 1 |

| 波形編集（トリム・ループ点） | 波形を見ながら START / END / LOOP をドラッグ。ノーマライズ・逆転・切り詰め | 2 |
| チョップ（スライス） | 等分・音の立ち上がりで自動・手で印を付ける → 連続するパッドに並べる | 2 |

| 16 レベル | 1 つの音を 16 パッドに、音程（またはフィルター・音量）を段々に並べる | 2 |

## フェーズ1の操作

| 操作 | やり方 |
|---|---|
| 音を出す | パッドを押す（最初の 1 回で音が出る準備をする）。押した高さで強さが変わる（上 = 強い） |
| パッドを選ぶ | 押したパッドが「いまのパッド」になり、画面とノブがそのパッドの設定になる |
| バンク | ◀ ▶ か A〜J のボタン |
| ノブ 4 つ | 上の SOUND / FILTER・ENV / SAMPLE でページを切り替え。上下ドラッグ・ホイール、ダブルクリックで初期値 |
| GATE・LOOP・REV・POLY | いまのパッドの再生のしかた |
| 録音 | REC（点滅）→ 録りたいパッドを押す → 録音中（AUTO が点いていれば音が来るまで待つ）→ もう一度 REC で止めて、そのパッドに入る |
| リサンプル | RESAMPLE → パッドを押す（そのパッドに録る）→ ほかのパッドを鳴らす → RESAMPLE で止める |
| ファイル | 📂 → ファイルを選ぶ → いまのパッドに入る。PC はパッドにファイルを落としてもよい |
| コピー | COPY（いまのパッドがコピー元）→ 貼り付け先のパッドを押す |
| 消す | DEL → 消すパッドを押す（もう一度 DEL で取りやめ） |
| PC のキー | Z X C V = パッド 1〜4、A S D F = 5〜8、Q W E R = 9〜12、1 2 3 4 = 13〜16（並びがパッドと同じ形）。[ ] = バンク、スペース = STOP |
| 最初の音に戻す | 画面右上の「工場出荷」：バンク A（ドラム）・B（おもちゃの音・ループ）を作り直す（ほかのバンクはそのまま） |

## 音の作り（`src/sampler/dsp/engine.ts`）

- ボイス 32 個。サンプルの再生位置を小数で進め、直線補間で読む。速さ = サンプルのレート ÷ 出力のレート × 2^(半音/12)
- エンベロープ：ATTACK は直線（0〜2 秒）、RELEASE は指数（5ms〜4 秒）。止められる音（チョーク・押し直し）は 3ms で消して、プチッと鳴らさない
- フィルター：ステート・バリアブル・フィルター（ローパス）。CUTOFF 20Hz〜20kHz、RESO で山を立てる。全開・山なしなら素通り
- 音量 = VOL² × 2 × ベロシティの効き。パンは等パワー
- 出口：マスター音量 → やわらかいクリップ（大きすぎる音をなめらかに丸める）
- 録音：入力（マイク）または出力（リサンプル）を最大 120 秒。AUTO は入力の山がしきい値を超えたら始める
- 工場出荷の音（`dsp/factory.ts`）は、すべてプログラムで合成する（録音素材は使わない）。乱数はシード付きなので、いつも同じ音
