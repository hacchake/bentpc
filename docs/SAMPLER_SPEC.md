# PAKU-PAKU 16（音を食べるサンプラー）仕様

スマホ・タブレット・PC のブラウザで使うサンプラー。見た目は「子ども用の録音おもちゃを魔改造した」もの。
定番のハードウェアサンプラー（パッド型の SP 系・MPC 系）の機能を、オリジナルの名前で網羅する。実在の製品名・ロゴは画面に出さない。

- ページ：`sampler.html`（ラック・スタジオの上のバーからも行ける）
- コード：`src/sampler/` にまとめる（あとでサンプラー単体のアプリに切り出せるように、ほかのおもちゃのコードには依存しない。使うのは `src/core/controls.ts` のノブと `src/core/rng.ts` の乱数だけ）
  - `src/sampler/dsp/` … 音の処理（DOM 非依存。将来 VST3 などに移すときはここだけ持っていく）
  - `src/sampler/worklet.ts` … AudioWorklet の殻
  - `src/sampler/host.ts` … AudioContext・マイク・ファイル読み込み
  - `src/sampler/store.ts` … ブラウザ内の保存（IndexedDB）
  - `src/sampler/main.ts`・`ui.ts`・`sampler.css` … 画面
- ステレオ（ほかのおもちゃはモノラル）

## フェーズ1の操作

| 操作 | やり方 |
|---|---|
| 音を出す | パッドを押す（最初の 1 回で音が出る準備をする）。押した高さで強さが変わる（上 = 強い） |
| パッドを選ぶ | 押したパッドが「いまのパッド」になり、画面とノブがそのパッドの設定になる |
| バンク | ◀ ▶ か A〜P のボタン |
| ノブ 4 つ | 上の SOUND / FILTER・ENV / SAMPLE でページを切り替え。上下ドラッグ・ホイール、ダブルクリックで初期値 |
| GATE・LOOP・REV・POLY | いまのパッドの再生のしかた |
| 録音 | REC（点滅）→ 録りたいパッドを押す → 録音中（AUTO が点いていれば音が来るまで待つ）→ もう一度 REC で止めて、そのパッドに入る |
| リサンプル | RESAMPLE → パッドを押す（そのパッドに録る）→ ほかのパッドを鳴らす → RESAMPLE で止める |
| ファイル | 📂 → ファイルを選ぶ → いまのパッドに入る。PC はパッドにファイルを落としてもよい |
| コピー | COPY（いまのパッドがコピー元）→ 貼り付け先のパッドを押す |
| 消す | DEL → 消すパッドを押す（もう一度 DEL で取りやめ） |
| PC のキー | Z X C V = パッド 1〜4、A S D F = 5〜8、Q W E R = 9〜12、1 2 3 4 = 13〜16（並びがパッドと同じ形）。[ ] = バンク、スペース = STOP |
| 最初の音に戻す | 画面右上の「工場出荷」：バンク A〜G を作り直す（H〜J はそのまま）。A = ドラム、B = おもちゃの音・ループ、C = 和（太鼓・締太鼓・チャンチキ・手拍子・拍子木・鐘・掛け声・三味線・琴・尺八・ストリングス・泣きのギター・ウッドベース・篠笛・鈴）、D = レゲエ・ダブ・スカ（ワンドロップ・リムショット・スカンク・オルガン・ダブベース・サイレン・スプリングのスネア・ホーン・メロディカ・ダブの一発・アケテ・スカのピアノ）、E = ジャズ・ボサノバ・ファンク（ブラシ・ライド・クロススティック・ウッドベース・エレピ・ナイロンギター・クラビ・スラップ・サックス・ビブラフォン・クラーベ・カバサ・コンガ）、F = ダンス（909・808・リース・アシッド・ハウスピアノ・スーパーソウ・ガバキック・ブレイクのスネア・トラップのハット・ヘイ！）、G = マーチ・チップ・パンク・ローファイ（大太鼓・小太鼓・シンバル・グロッケン・ブラス・チューバ・四角波・ノイズ・三角波・パワーコード・ロックのキック/スネア・ローファイのキック/スネア/エレピ・レコードのチリチリ）。前の版で保存した人には、C〜G の空いているパッドにだけ自動で入れる（meta.factoryVer） |

## フェーズ2の操作（機能ボタンは PAD / PLAY / EDIT のタブ）

| 操作 | やり方 |
|---|---|
| ROLL | PLAY タブ。点けると、押している間（サブパッドも）1/4・1/8・1/16・1/32・1/8T・1/16T でくり返す。速さは TEMPO。時刻はサンプル単位でぴったり |
| SUB PAD | 最後に鳴らしたパッドをもう一度（押している間） |
| 16 LEVELS | いまのパッドの音を 16 パッドに並べる。PITCH（パッド 9 が元の高さ、1 が −8・16 が +7 半音）・VEL・CUTOFF・ATTACK・START（鳴らし始めを 16 段にずらす） |
| TEMPO・TAP | 40〜240 BPM。TAP を 2 回以上押した間隔から |
| WAVE EDIT | EDIT タブ。大きな波形で START（緑）・END（赤）・LOOP（青。LOOP のとき 2 周目からここに戻る）をドラッグ。◀ ▶ で 1ms・◀◀ ▶▶ で 10ms、0 SNAP で近くの「波が 0 を横切る所」へ、🔍 ZOOM で START〜END を拡大 |
| CHOP | 等分（2・4・8・16）／AUTO（音の立ち上がり。細かさ − ＋）／手で（波形をタップで切れ目、切れ目をタップで消す・ドラッグで動かす）。「→ パッドに並べる」で、からっぽのバンクのパッド 1〜に並べる（無ければ、いまのバンクに上書きしてよいか聞く） |
| TEMPO FIT | 音の BPM を推定（くり返しの間隔と、長さが 1・2・4・8・16 小節になることから）。− ＋ ÷2 ×2 で直せる。「音程そのまま（STRETCH）」は WSOLA で長さだけ変える。「速さだけ」は PITCH・FINE で速さを合わせる（音程も変わる） |
| NORMALIZE・REVERSE・TRIM・UNDO | 音量をそろえる・逆向きにして保存・START〜END だけ残す。編集は 1 回だけ UNDO で戻せる |
| MIX ページ | MUTE GRP と、この音の BPM（SMPL BPM） |

## フェーズ3：エフェクトとサーキットベンド

FX タブで置き場所（BUS 1・BUS 2・MASTER）を選び、◀ ▶ で種類、FX ON、ノブ（FX ページ）で調整。パッドの送り先は FX タブか MIX ページの BUS。
音の流れ：パッド → （DRY／BUS 1 のエフェクト／BUS 2 のエフェクト）→ 足す → MASTER のエフェクト → ベンド → 音量 → やわらかいクリップ。

| # | エフェクト | ノブ 1〜4 |
|---|---|---|
| 1 | FILTER+DRIVE | CUTOFF・RESO・DRIVE・TYPE（LPF/BPF/HPF） |
| 2 | ISOLATOR | LOW・MID・HIGH（左いっぱいで消える、まん中で等倍）・MIX |
| 3 | LO-FI | BITS（16〜2）・RATE（間引き）・TONE・MIX |
| 4 | VINYL SIM | NOISE（パチパチ）・WOW（回転むら）・AGE（こもり）・MIX |
| 5 | CASSETTE SIM | WOW（ゆれ）・SATURATE・HISS・TONE |
| 6 | SYNC DELAY | TIME（1/16〜1 小節、TEMPO に合わせる・ピンポン）・FEEDBACK・TONE・MIX |
| 7 | TAPE ECHO | TIME（50〜800ms。動かすと音程がゆれる）・FEEDBACK（100% 超えで発振）・WOBBLE・MIX |
| 8 | REVERB | SIZE・DECAY・TONE・MIX |
| 9 | CHORUS | RATE・DEPTH・WIDTH・MIX |
| 10 | FLANGER | RATE・DEPTH・FEEDBACK（±）・MIX |
| 11 | PHASER | RATE・DEPTH・FEEDBACK・MIX |
| 12 | COMPRESSOR | THRESH・RATIO・RELEASE・MAKEUP |
| 13 | DJ LOOPER | LENGTH（1/16〜1 小節）・HOLD（右に回すと、その直前をくり返す）・SPEED（×0.25〜×2）・REVERSE |
| 14 | SLICER | RATE（1/32〜1/4）・PATTERN（8 種）・DEPTH・SMOOTH |
| 15 | RING MOD | FREQ・WOBBLE・TONE・MIX |
| 16 | TREMOLO/PAN | RATE（TEMPO に合わせる）・DEPTH・MODE（音量／左右）・SHAPE（なめらか〜カクカク） |
| 17 | AUTO WAH | SENS（音の大きさで開く）・LFO・RESO・MIX |
| 18 | EQ | LOW・MID・HIGH（±15dB）・MID FREQ |
| 19 | DISTORTION | DRIVE・TONE・LEVEL・MIX |
| 20 | PITCH SHIFT | PITCH（±12 半音）・WINDOW・FEEDBACK・MIX |
| 21 | TAPE STOP | TIME（止まるまで）・STOP（右に回すと止まる）・—・MIX |
| 22 | SCATTER | RATE・DEPTH（起こる確率）・TYPE（くり返し／逆／半分の速さ／おまかせ）・MIX |
| 23 | RESONATOR | NOTE（C2〜C6）・FEEDBACK・TONE・MIX |
| 24 | TOY SPEAKER | SIZE（小さなスピーカーの鳴る帯域）・RATTLE（大きい音でビビる）・CRUNCH・MIX |

テンポに合わせるもの（SYNC DELAY・DJ LOOPER・SLICER・TREMOLO・SCATTER）は TEMPO と拍の位置で動く（止まっていても時計で進む。フェーズ4 の再生中は曲の位置）。

### サーキットベンド（BEND タブ）

むき出しの基板のジャンパー線 6 本。つなぐと出口の音とパッドの再生が壊れる。ノブ（BEND ページ）は AMOUNT（強さ）・SPEED（頻度）。

| 線 | 起こること |
|---|---|
| CLOCK | 再生の速さが ±1 オクターブの間でカクカク飛ぶ |
| STUCK | 出口の 8〜100ms を切り取って、何回かくり返す |
| RUNAWAY | 音程がふらふら上がり下がりして、ときどきパチンと戻る |
| BIT ROT | ビットが落ちる・値が一瞬固まる・たまに反転 |
| CROSSTALK | パッドを鳴らすと、同じバンクのほかのパッドも小さく鳴る |
| SAG | 大きい音を出すと電池がへたるように小さく・こもって・低くなる |

熱：つないだ本数 × 出している音の大きさでたまり、0.8 を超えると暴発（全部の線が一時的に強く効く）。外せば冷める（固まらない。ほかのおもちゃと同じ方針）。熱いと本体が赤く光り、液晶の色が狂う。

## フェーズ4：パターン・ソング・書き出し（`dsp/seq.ts`・`dsp/export.ts`）

| 操作 | やり方 |
|---|---|
| ▶ PLAY | PATTERN タブ。いまのパターンをくり返す（スペースキーでも止まる） |
| ● REC | 止まっていれば頭から録音しながら再生、再生中なら録音の入／切。叩いた音は QUANT（OFF・1/8・1/16・1/32・1/8T・1/16T）にそろえて、離したときに入る（押していた長さも覚える＝GATE のパッドはその長さで止まる）。次の周から鳴る |
| METRO | クリック（小節の頭は高い音）。書き出しには入らない |
| PATTERN | 押してから、パッドで P01〜P16 を選ぶ。再生中に選ぶと、いまのパターンの終わりで替わる |
| 小節 − ＋・CLEAR | 1〜8 小節。CLEAR で全部消す |
| STEP | 選んでいたパッドの音を 16 分のマスで置く／消す。パッドがステップになる（左上が 1、右下が 16）。◀ ▶ で何小節目か |
| ERASE | 点けてからパッドを押すと、そのパッドの音がパターンから全部消える |
| ↶ | パターンの編集・録音を 1 つ戻す |
| SWING | SEQ ページのノブ。16 分の裏を遅らせる（50%〜75%） |
| SONG タブ | ＋ でいまのパターンを、選んだ所の後ろにつなぐ。× ± でくり返し回数、削除、▶ SONG で鳴らす（終わったら止まる） |
| ⤓ WAV パターン / ソング | 44.1kHz・16bit・ステレオ。パターンは 2 回分、ソングは全部。最後に 2 秒の余韻。エフェクトとベンドもそのまま入る（ベンドの乱数もシード付きなので毎回同じ） |
| ⤓ MIDI | ソングがあればソング、無ければいまのパターン。バンク A〜P = チャンネル 1〜10、パッド 1〜16 = ノート 36〜51、テンポ入り |
| 💾 保存 / 📂 読込 | プロジェクト丸ごと（256 パッドの音と設定・エフェクト・ベンド・パターン・ソング・テンポ）を 1 つのファイル（.paku）に。音は 16bit |
| ⤓ WAV（EDIT タブ） | いまのパッドの音だけ |

シーケンサーは AudioWorklet の中で動き、音はサンプル単位の時刻で鳴る（128 サンプルのブロックの途中でも）。テンポに合わせるエフェクトは再生中、パターンの拍の位置で動く。

## フェーズ5：スタジオ（DAW）との連携

- 7 台目のおもちゃとして `src/toys/engines.ts`・`uis.ts` に登録（`src/sampler/toy/`）。ほかのおもちゃと同じ扱い：ラックの 7 つ目のタブ（F7・MIDI チャンネル 7）、スタジオの「おもちゃを選ぶ」、電源ボタン（パクッ、パクッと鳴って起動）、自動作曲ユニット
- キー 160〜207 = メロディ（MELO PAD の音を ±24 半音、184 が元の高さ）、208〜255 = ベース（BASS PAD の音、232 が元の高さ・1 音ずつ）、256〜303 = 和音（CHORD PAD の音、280 が元の高さ・重ねて弾ける。離したキーの音だけ止まる＝TrigMod の tag）。重なっても中で歪まないよう、エンジンの合計は 0.7 倍にして出口で戻し、大きすぎる所だけやわらかく抑える。パラメーター：VOLUME・STOP・MELO PAD・BASS PAD・CHORD PAD（最後に追加、16 番）・BEND（上げるほどジャンパー線が増える）・後付けの改造パーツ（PITCH ±12・START・CUTOFF・RESO・DRIVE・CRUSH・ECHO・E.TIME・B.SPEED・REV・FX）。出口の順は CRUSH → DRIVE → ローパス → ECHO → VOL（音量はいちばん後ろ）。液晶には波形・鳴らす範囲・再生位置
- 自動作曲（`src/compose/toys/sampler.ts`）：スタイルごとの楽器セット（`KITS`。キック・スネア・ハット・メロディ・ベース・和音の楽器と刻み方・サビでの持ち替え）で弾く。例：音頭 = 太鼓・チャンチキ・手拍子・掛け声「よーいっ」・篠笛・三味線、演歌 = 琴のイントロ → 尺八 → サビは泣きのギター・ストリングス、レゲエ = ワンドロップ・2 4 拍のスカンク → サビはオルガンのバブル、ジャズ = ライド・ブラシ・ペダルハット・ウッドベース・サックス・エレピ。表に無いスタイル（素朴・ビートなど）はバンク A・B のおもちゃの音。楽器は「元の高さ」（`factory2.ts` の `ROOTS`）の近くで弾くようにオクターブを動かす。drums・bass・melody・chords（CHORD PAD）・mods（電源・クラッシュ・音量・BEND を壊れ度で・盛り上げで CUTOFF を開く・ブレイクとアウトロで付点 8 分の ECHO・壊れ度で CRUSH と DRIVE・ZAP や RISER のワンショット）。合同の曲では、ビートを刻む係の 2 番目の候補（TELEKEY の次）、メロディの掛け合いにも入る
- エンジンは最初から工場出荷の 112 音（A〜G）を持っている（作るのに 1 秒ほど。1 回だけ作って使い回す）（サンプラーのページを開いたことがなくても鳴る）。保存した音があれば上書き
- キー 0〜159 = パッド A-01〜J-16、304〜399 = パッド K-01〜P-16（あとから増やしたバンク。前に作った曲のキーがずれないよう後ろに足した）。シーケンサーの行の名前は「A-01 KICK」など。強さはパッドの VEL の設定で 1.0 として鳴る（スタジオのシーケンサーには強さが無いため）
- 音と設定は、サンプラーのページでこのブラウザ（IndexedDB）に保存したものを、スタジオの画面が読んで `custom` メッセージでエンジンへ送る（無ければ工場出荷の音）。エンジンを作り直したとき（頭から再生）も送り直す。WAV の書き出しにも同じデータを渡すので、同じ音になる
- 「↻ 読み直す」：サンプラーのページで音を変えたあとに
- SONG タブの「→ STUDIO」：ソング（無ければいまのパターン）を、スタジオの曲（サンプラーだけを並べた画面 `studio.html?toys=6`）に入れて開く。スイングは音符の位置に焼き込む。パターンごとにセクション名（P01 など）
- MIDI の書き出し（スタジオ）：サンプラーはノート 36〜51（パッド番号）

## 切り出すとき

- サンプラーだけのアプリにする：`src/sampler/`（`dsp/`・`main.ts`・`editor.ts`・`host.ts`・`store.ts`・`worklet.ts`・`sampler.css`）と、`src/core/controls.ts`（ノブ）・`src/core/rng.ts`（乱数）・`src/core/parts.css`（部品の見た目）・`sampler.html`。`src/sampler/toy/` はスタジオ用なので要らない
- DAW（スタジオ）といっしょに切り出す：上に加えて `src/studio/`・`src/host/`・`src/core/` と `src/sampler/toy/`。おもちゃの一覧（`src/toys/engines.ts`・`uis.ts`）をサンプラーだけにする

## 音の作り（`src/sampler/dsp/engine.ts`）

- ボイス 32 個。サンプルの再生位置を小数で進め、直線補間で読む。速さ = サンプルのレート ÷ 出力のレート × 2^(半音/12)
- エンベロープ：ATTACK は直線（0〜2 秒）、RELEASE は指数（5ms〜4 秒）。止められる音（チョーク・押し直し）は 3ms で消して、プチッと鳴らさない
- フィルター：ステート・バリアブル・フィルター（ローパス）。CUTOFF 20Hz〜20kHz、RESO で山を立てる。全開・山なしなら素通り
- 音量 = VOL² × 2 × ベロシティの効き。パンは等パワー
- 出口：マスター音量 → やわらかいクリップ（大きすぎる音をなめらかに丸める）
- 録音：入力（マイク）または出力（リサンプル）を最大 120 秒。AUTO は入力の山がしきい値を超えたら始める
- 予定（ロールの連打、のちにパターン）は、128 サンプルのブロックの途中でもその時刻で区切って鳴らす
- 編集（`dsp/edit.ts`）：ストレッチは 40ms の窓・半分ずつ重ね、±8ms の範囲で前の窓といちばん形が合う所を探してつなぐ（WSOLA）。チョップの AUTO は 5ms ごとの音の大きさ（対数）の増え方の山
- 工場出荷の音（`dsp/factory.ts`、ジャンル編は `dsp/factory2.ts`）は、すべてプログラムで合成する（録音素材は使わない）。弦はカープラス・ストロング、エレピは FM、オルガンは倍音の足し算、ブラス・ストリングスは帯域制限ののこぎり波 ＋ 動くフィルター、声はフォルマント。乱数はシード付きなので、いつも同じ音。C〜G は 1 音ずつ作れる（画面の液晶は見るときだけ作る）
