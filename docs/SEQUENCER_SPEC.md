# シーケンサー仕様書（BENT TOY RACK の DAW 部分）

演奏を「音」ではなく**操作（どのキーをいつ押したか・どのツマミをどう動かしたか）**として記録する。
おもちゃの DSP はシード付きで決定的なので、同じ操作を同じタイミングで入れれば同じ音になる（`scripts/seq-test.ts` で確認）。
そのため、録ったあとで音符やツマミの動きを細かく直せる。

## ファイル

- `src/core/song.ts` … 曲データの形、生の操作 → 音符・ツマミの動きへの変換（Worklet と画面で共通）
- `src/host/sequencer.ts` … Worklet の中で動く本体（再生・録音・メトロノーム）。DOM 非依存
- `src/host/daw.ts` / `daw.css` … 編集パネル（画面の下）
- `src/host/worklet.ts` … シーケンサーを使っておもちゃを動かす

## 曲データ（Song）

```ts
Song = { version: 1, bpm, bars, metronome, tracks: SeqTrack[] }   // おもちゃ 1 台 = 1 トラック（並び = おもちゃ番号）
SeqTrack = { mute, notes: SeqNote[], autos: SeqAuto[] }
SeqNote = { key, start, len, take }   // key はおもちゃのキー番号。start/len は拍
SeqAuto = { index, t, v, take }       // index はおもちゃのパラメーター番号
```

- 4/4 拍子。曲の長さ = `bars × 4` 拍 = ループの長さ。
- 時間はすべて拍。BPM を変えても位置関係は保たれる。
- 画面では `localStorage`（`bentpc.song.v1`）に自動保存。「保存」「読込」で JSON ファイルにも出し入れできる。

## 録音（オーバーダブ）

1. REC を押すと（止まっていれば再生も始まる）、テイク番号 = 今までの最大 + 1 で録音開始。
   録音開始の時点で押しているキーは、その位置から押したことにする。
2. おもちゃへの操作（`key` / `param`）が Worklet に届くたびに、その時点の拍位置つきで生の操作として集める
   （位置はブロックの先頭 ＝ 最大 128 サンプル ≒ 2.7ms の誤差）。
3. **ループの終わりに来るたび**、集めた操作を `takeFromRaw` で音符（押した〜離した）とツマミの点に変換し、曲に**足す**。
   同じものを画面にも送る（`seqTake`）。そのため次の周からは、いま録った演奏も一緒に鳴る。
   押しっぱなしのキーはループの終わりで切り、次の周の頭から続きを録る。
4. もう一度 REC を押すか、停止すると、そこまでの分を同じように足して録音を終える。
- ツマミの点は 1/64 拍より細かい変化を間引く（最後の値は残す）。
- 録音を始める直前の曲を「元に戻す」に積むので、UNDO でそのテイクを丸ごと取り消せる。

## 再生

- 各ブロック（128 サンプル）で、その範囲に入る音符の始まり・終わり、ツマミの点を**サンプル位置つき**で集め、
  おもちゃごとにブロックをその位置で区切って処理する（`process(tmp.subarray(a, b))`）→ サンプル単位で正確。
- ループの終わりでシーケンサーが押しているキーをすべて離し、頭に戻る。
- ミュートしたトラックは鳴らさない。
- 停止・曲の差し替え（編集）のときも、シーケンサーが押しているキーを離す。
- 再生・録音・BOUNCE の前に、音符が入っているトラックのおもちゃは電源を入れる。

## メトロノーム

拍ごとに 1320Hz（小節の頭は 1760Hz）の 30ms のクリック。**録音（REC・BOUNCE）には入らず**、スピーカーにだけ出る。

## BOUNCE

音の録音（REC）を開始 → 曲を頭から 1 回だけ鳴らす（ループしない）→ 終わったら録音を止めて WAV をダウンロード。

## 編集パネル

- **トラック一覧**：選ぶとそのおもちゃの音符を表示。M でミュート。
- **ピアノロール**：行 = 使っているキー（＋「行を追加」で足したキー）。行の名前はおもちゃごとの `keyName`。
  - クリックで選択（Shift で追加）、ドラッグで移動（上下で別のキーへ）、右端をドラッグで長さ、ダブルクリックで追加、右クリックで削除
  - グリッド 1/4〜1/32（OFF で自由）、QUANTIZE（選んだ音符、なければ全部の頭と長さをグリッドにそろえる）
  - ホイール：上下スクロール、Shift＋ホイールで左右、Ctrl＋ホイールで拡大縮小
- **ツマミの動き**：パラメーターを選ぶと、点と階段状の線で表示。ダブルクリックで点を追加、ドラッグで移動、右クリックで削除。
- パネルの中をクリックした後は、キーボードが編集用になる：Delete/BS=削除、Space=再生/停止、矢印=選んだ音符を動かす、
  Ctrl+Z / Ctrl+Y = 元に戻す / やり直し、Ctrl+A = 全部選ぶ、Esc = 選択解除。おもちゃの画面をクリックすると演奏用に戻る。

## いまの制限

- 再生中のツマミの動きは音には反映されるが、画面のツマミの位置は動かない。
- おもちゃ自身のリズム（PIKOTONE・SPIN-TOT・TYPOTRON のループ）のテンポは、曲の BPM とは連動しない。
