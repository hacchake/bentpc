# DSP 仕様書：VROOMBOX VR-5（4台目・オリジナル設計）

子供用のハンドル付きドライブ・ダッシュボードを魔改造した、という設定のオリジナル楽器。
コードは `src/toys/vroom/dsp/`（DOM・Web Audio に依存しない）。パラメーターは `src/toys/vroom/params.ts`。

## 信号の流れ

```
セルモーター ─────────────────────────────┐
点火の粒 → 排気管の共振×2 ＋ チップ音 → SPARK → HAZARD → TURBO FB → RADIO BLEED ─┤×0.7
ラジオ（ROM）→ 小さなスピーカー ─────────────────────┤
ターボ・ホーン・サイレン・ウインカー・ワイパー・クラッシュ・ギア鳴き・タイヤ鳴き・ハム ┘
  → DC カット → tanh → 音量² × 電源ゲート
```

## キー番号

| 番号 | 内容 |
|---|---|
| 0〜7 | ラジオのプリセット（PRESET HIJACK 中はエンジンの音階 C3〜C4 の長音階） |
| 8 | ホーン（押している間） |
| 9 | クラッシュ |
| 10 | セルを回す（押している間） |
| 16〜75 | MIDI ノート 36〜95 でエンジンを直接弾く（点火の周波数 = ノートの周波数） |

## 始動と回転数

- 電源（キー ON）のあと、START を押している間セルモーターが回る（118Hz のこぎり＋4.5Hz でうねるノイズ）。
  0.5〜1.1 秒（乱数）でエンジンがかかり、1300rpm から。
- 目標回転数 `850 + throttle^1.3 × (上限 - 850)`、上限 = `7000 × 2^(3·REDLINE)`。TURBO 中は ×1.2。
  時定数：ニュートラル 0.08 秒、ギア g では `0.12 + 0.12·g` 秒で追従。
- ギアを変えた瞬間、回転数 × (新ギア比 / 旧ギア比)。ギア比 `[N, 3.5, 2.1, 1.4, 1.0, 0.8]`。
- 速度 `rpm × 0.02 / ギア比` km/h（N では 4 秒の時定数で惰性で落ちる）。
- REDLINE = 0 のときは 6860rpm 超で 50% の点火を飛ばす（リミッター）。

## 点火（エンジン音の中心）

- 点火の周波数 `F = rpm / 30` Hz（HIJACK・MIDI ノート中はノートの周波数）。
  **TUNE**：F を一番近い半音にそろえる。
- 点火の位相が 1 周するたびに CAM の長さ（3〜8）のステップを 1 つ進め、そのステップの **FIRING ORDER** スイッチが ON なら点火。
  CHASSIS に触っている間は `0.4 × 触れ具合` の確率で点火が飛ぶ。
- 点火 1 回 = 包絡 1 から `exp(-t/τ)`、`τ = min(12ms, 0.6/F)`。音源 `包絡 × (0.6 + 0.4·ノイズ)`。
- 排気管：状態変数フィルターのバンドパス 2 段（140Hz 減衰 0.8 × 1.4 ×（1 + 1.5·CHASSIS）、520Hz 減衰 0.5 × 0.7）。
- チップ音：包絡が 0.02 を超えている間、点火の位相で 30% デューティの矩形 × 包絡 × 0.3。
- **SPARK**：点火ごとに 1.5ms のノイズ（× SPARK × 0.9）、`8 - 5·SPARK` ビットに量子化。
- **HAZARD**：`1.5 + 12·h` Hz の矩形でエンジンを刻む（深さ h）。リレーのカチカチも `20·h` 回/秒 増える。
- **TURBO FB**（ON のとき）：遅れ `sr/F`（点火 1 回ぶん）の櫛形フィードバック `+ tanh(遅れた値 × fb × 1.1)` → 回転に合わせて響く金属音。
- **RADIO BLEED** b：`エンジン × (1-b) + エンジン × ラジオ × 8b`（掛け算で混ざる）、ラジオ自体は点火のない所で `1 - 0.8b` まで下がる。

## 付属の音

- ラジオ：3 局（FM1 124BPM・FM2 92BPM のオリジナル曲、AM のしゃべり＋雑音）を 8kHz の ROM からループ。
  局を変えると 0.3 秒の雑音。小さなスピーカー（1 次ローパス 0.3）× 0.5。
- ターボ：押している間 0.3 秒で立ち上がるノイズ（中心 `800 + 0.4·rpm` Hz）＋ `0.9·rpm` Hz の笛。離すと 0.25 秒のプシュー。
- ホーン：392Hz と 494Hz の矩形を tanh。**HORN BEND** ON ではハンドル（-1〜1）で `×2^wheel`。
- サイレン：700〜1100Hz を 0.8Hz で上下する矩形。
- ウインカー：1.5Hz のリレーのカチ（1300Hz）・コチ（1000Hz）。ワイパー：1.3 秒ごとのシャー。
- クラッシュ：爆発ノイズ＋5 つの非整数倍音の金属音＋ガラスのチリチリ（ROM）。
- **GEAR GRIND** ON：ギアを変えるたびに 0.6 秒、3kHz のノイズを 43Hz で刻むガリガリ。走行中の回転数も 3Hz でふらつく。
- タイヤの鳴き：ハンドルを回す速さ × 速度で 2.5kHz のノイズ（30Hz で揺れる）。
- **CHASSIS**：50Hz のハム（サイン＋矩形）× 0.12 × 触れ具合。
- **STARTER LOOP**：押している間、エンジンがかかっていてもセルモーターの音が回り続ける。

## 表示・状態

- 表示 `display.text`：スピードメーターの数字（3 桁）。
- `status().fx`：`rpm`（10 単位）、`speed`、`gear`。`leds`：`running`、`signal`（点滅）、`turbo`。
